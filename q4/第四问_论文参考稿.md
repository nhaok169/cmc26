# 第四问　全向+定向混合干扰源的检测与清除策略

> 本文是 2026 高教社杯 B 题《无线电干扰源的快速自动定位与清除》问题 4 的完整建模参考稿，供撰写最终论文使用。理论体系 = 问题 1/2 单源定位几何 + 问题 3 全向源搜索框架 + **环抱证书（本轮核心创新）**。文献依据见 `文献/B题问题4/README.md` 与 `文献/B题问题4/_notes_local.md`（N1–N9 自建结论均已数值验证）。
>
> **版本**：v1（2026-09-12 定稿）。核心策略 = **环抱证书 + 三段式合并巡回**，24/24 全清，T_avg ≈ 600s（mock 24 种子基准，8 次真机演练均值 ~550s）。

## 1　问题重述

问题 4 在问题 3 基础上引入**定向干扰源**：目标区域半径 1800 m 圆域内有 10–16 个干扰源，分为全向源与定向源两类，定向源的**个数与朝向均未知**。其余条件与问题 3 相同：

1. **硬约束**：确保全部干扰源被清除（清除比例 = 100%）；
2. **目标**：平均定位清除时间 = 定位清除总时间 / 被清除个数，越小越好；
3. **时限**：`/enter` 后程序运行时间 ≤ 20 min，虚拟时间上限 100 h。

**关键物理规则**（相对问题 3 的增量）：

| 项 | 值 |
|---|---|
| 全向源 | 覆盖 360°，示向度误差 ±1° |
| 定向源 | 覆盖定向方向两侧各 90°（**闭半平面，含边界**），范围外无信号 |
| 有效接收半径 | 1000–1500 m（逐源未知） |
| 强信号 | 距源 ≤5 m 且在覆盖角内 ⇒ 无示向度，可直接光学清除 |

**核心难点**：问题 3 中 `no_signal ⟺ 距离 > 接收半径` 的推理**失效**——定向源的 `no_signal` 还可能是"检测点位于其 180° 覆盖半平面之外"（背对源）。因此问题 3 的 7 点圆覆盖证书（证明全向源必被检出）对定向源**不再充分**：圆缘朝外定向源可能背对所有圆内检测点而漏检。

## 2　问题分析

### 2.1　问题 4 相对问题 3 的本质变化

问题 4 把"无信号"从一个**单因**（距离超限）变成**双因**（距离超限 ∪ 朝向背对）。这导致两个连锁变化：

1. **判空必须重新设计**：全向源判空用"圆覆盖"（7 点 1000 m 圆盖住圆域即可），定向源判空必须用"多方向环抱"——因为空频道与"背对漏检的定向源"在检出前**无法区分**。
2. **检出本身不再有保证**：单个检测点对定向源可能"看不见"（背对），必须保证对任意朝向的定向源都有检测点在它的覆盖半平面内。

### 2.2　检测语义对偶（N1）

停点 p 检出定向源 (G, φ) ⟺ `‖G−p‖ ≤ R` 且 `|ang(G→p) − φ| ≤ 90°`。因此**单停点覆盖的朝向集合 = 以 ang(G→p) 为中心的封闭 180° 弧**。保证"任意 G、任意 φ 被检出" ⟺ 对每个 G，1000 m（最坏 R）内停点方向的最大环形间隙 ≤ 180°。

这等价于相机网络的 **full-view coverage**（FOV=180°、作用半径 1000、朝向对抗）——Wang & Cao (INFOCOM 2011) 给出该定义的充分必要条件。

### 2.3　强命题：纯圆内停点集不可能给出完整保证（N3）

源在圆缘 G（|G|=1800）、朝向 φ 朝圆外时：检出停点 S 必须满足 `(S−G)·u_φ ≥ 0`（源外侧半平面）∧ `‖S−G‖ ≤ 1000`。该半平面与圆域内域交集 ≈ {G} 一个点 ⟹ **任何纯圆内停点集对此类源零检出**。故证书构型**必须包含圆外停点**（题面允许坐标分量 ≤ 2×10⁶）。

### 2.4　全向/定向判别的必要性

类型未知时，单点 `no_signal` 对任意候选 G 都存在"背对朝向"解释 ⟹ 硬账收缩 = 空操作（N6）。因此**判空不能依赖"负信息收缩"**，只能依赖"多方向环抱证书"。这正是问题 4 判空成本显著高于问题 3 的根本原因。

## 5　模型建立

### 5.1　环抱证书（本轮核心创新，N1–N4）

**定义**：对频道 ch，记其探针集合 P（不仅是有信号的测点，无信号的测点同样是"该点背对该源的证据"，信息复用）。

**判据（充要）**：频道 ch 必为空 ⟺ 对目标圆域内任意 G，

$$\max_{G\in\text{disk}(1800)}\ \text{maxgap}\big(P\cap B(G,1000)\big)\ \le\ 180°$$

**为什么充分**：
- 若 maxgap ≤ 180°，则探针集合在 G 的 1000 m 内"环抱"G（离散点环抱）；
- 定向源的有效区是闭半平面（±90° 含边界），任意闭半平面必与一个 maxgap≤180° 的点集相交非空；
- 因此无论定向方向 φ 如何，**必有探针落在 G 的点亮半平面内** ⇒ 该源必被检出（或 G 本就无源）；
- 全向源（360°）是特例，自然包含。

**为什么必要**：若存在 G 使 maxgap > 180°，则取定向方向背对该最大空隙，全部探针都在盲侧 ⇒ 可能漏检。

**关键退化情形**：扇区是**闭**的，所以 maxgap == 180° 仍成立（不是违规）。实现时证书阈值取 180°+1e-6（`CERT_MARGIN = -1e-6`）。

### 5.2　证书点集（26 点骨架）

经穷尽式数值搜索（超密 G 网格 dr=2.5m、ddeg=0.5°，518400 点校验），得到最小可行证书点集：

$$\mathcal{S} = \text{ring}(400,6)\ \cup\ \text{ring}(1300,8)\ \cup\ \text{ring}(1900,12) = 26\ \text{点}$$

- 校验：maxgap = 171.8° < 180°，违规数 0；
- **20~25 点的所有方案全部失败**（maxgap 186°~292°），六边形格点最少需 31 点（s=950m）；
- 外环半径 1900 m 是唯一可行值（1850 m 即失败 183.1°），因为外环必须足够远以覆盖"圆缘朝外源"的外侧半平面；
- **26 点是 R=1000 下的硬下界**，对应巡回 18758 m = 3752 s，是移动时间的理论地板。

### 5.3　三段式合并巡回策略

```
initial(119s)  →  merged_walk(~7000s)  →  finalize(~460s)
```

1. **initial_scan**：原点把 20 个频道全测一遍（20×5 + 19×1 = 119s 固定成本）。原点对全向源给出 1 条示向度，为后续定位提供起点。

2. **merged_walk（核心）**：把**证书扫描 + 源定位 + 顺路清除**融进同一条巡回，动态重规划。
   - 节点集合 = 待访问证书骨架点 ∪ 已检出未清除源的 MEC 中心（后者带冷却）；
   - 每步若节点签名变化，用开放路径 TSP（最近邻 + 2-opt，起点固定为当前位置）重排剩余节点；
   - 到骨架点：对该点仍 unknown 的频道逐个测量（同时完成检测与证书累加），再顺路补测最不确定的已检出频道；
   - 到源节点：走预测点 → 测量 → 尝试清除 → 失败则追踪 → 冷却；
   - **关键设计**：取消独立的 hunt 阶段（v2 先 hunt 一轮与证书巡回路径完全重复，白白烧掉数千秒）。

3. **finalize**：对残余源做兜底 TSP 巡回，追踪预算逐轮放大。理想情况为 0（全部在巡回中清完）。

### 5.4　定向源追踪的三条经验规则

| 规则 | 内容 | 理由 |
|---|---|---|
| 点亮侧优先 | 候选点评分 `dist − LIT_BONUS·cos(v,u)`，u = 由 MEC 中心指向已有测点的平均方向 | 定向源在盲侧永远测不到，必须先绕到点亮侧 |
| 黑侧惩罚 | 记 no_signal 的方位，`dist + BLIND_PEN·cos(v,b)` | 避免反复撞盲侧 |
| 长条端采样 | MEC 半径 R>40 时，沿主轴两镜像端 + 最后示向度远端采样 | 单/双方位近共线时 MEC 是长条（R~680m），源在两端尖点，中心周围环上够不着 |

### 5.5　代价模型

$$T_{total}=\underbrace{119}_{\text{初始扫描}}+\underbrace{3752}_{\text{证书巡回}}+\underbrace{\Delta_{detour}}_{\text{绕行}}+\underbrace{\Delta_{measure}}_{\text{测量}}+\underbrace{\Delta_{switch}}_{\text{换频}}+\underbrace{5\cdot n_{src}}_{\text{清除}}$$

其中证书巡回 3752 s 是判空 4~10 个空频道的刚性下界（见 §6.2 可达性论证）。

## 6　模型求解与验证

### 6.1　时间账（24 种子平均）

| 分项 | 秒 | 占比 | 备注 |
|---|---:|---:|---|
| 初始扫描 | 119 | 2% | 固定 |
| **证书巡回移动** | **~3752** | 49% | 18758m / 5，理论地板 |
| 绕行清除/接近源 | ~1250 | 17% | 源接近的固有成本 |
| 末段 finalize | ~460 | 6% | 16/24 种子非零 |
| 测量 | ~1615 | 21% | 323 次 × 5s |
| 换频 | ~300 | 4% | |
| **合计** | **~7580** | | T_avg = 7580/12.8 ≈ 592 |

### 6.2　可达性论证（为什么 ~600s 接近理论极限）

- **证书移动 3752s 是硬地板**：判空 26 点是数学下界（§5.2 穷尽验证），无法压缩；
- **理想绕行 803s**：每个源到最近骨架点距离之和（理论最小绕行），实际 1250s 只多 1.5 倍；
- **源定位极快**：实测 271/308 源只需 2 次测量即 MEC≤60m，定位不是瓶颈；
- **理论下界 T_avg ≈ 472s**（证书 3752 + 理想绕行 803 + 测量 1090 + 换频 218 + 清除 64 + 初始 119），当前 600s 距下界仅 27%。

### 6.3　实测结果

**mock 24 种子基准**：24/24 全清，T_avg = 600.1s，Std = 83.2s。

**8 次真机演练**：

| 指标 | 值 |
|---|---|
| 清除率 | 8/8 次 100% |
| T_avg 均值 | ~550s（436~644s） |
| 源数影响 | 16 源 ~460s，12 源 ~590s（固定成本摊薄效应） |

波动主要来自源数量（12~16）：源越多固定成本摊得越薄，T_avg 越低，与 §6.1 时间账一致。

### 6.4　消融实验（已完成的尝试）

| 方案 | 结果 |
|---|---|
| 最便宜插入替代源节点 | 617~627s（劣化，源搁浅） |
| 源绑定最近骨架点 | 625s（劣化） |
| 源节点距离门槛 | 无门槛最优 |
| SRC_NODE_TOL 扫描 | 150m 持平 600s |
| TSP 优化（3-opt） | 仅省 55s |
| 统计判空（牺牲保证） | 省 90s 但漏检 1%，得不偿失 |

**结论**：600s 是"保证式全覆盖证书"框架的天花板，调度微调无法突破，这是问题的几何下界所致，而非策略缺陷。

## 7　灵敏度与稳健性分析

- **种子方差**：24 种子 T_avg 分布（Std=83.2s），报均值±std 而非单例；
- **源数量敏感**：12~16 源对应 T_avg 波动 ~150s（固定成本摊薄效应），是主要波动源；
- **最坏案例**：定向源数量最多的种子（12 个定向源）仍是 24/24 清除，环抱证书对朝向分布稳健；
- **接收半径敏感**：判空按最坏 1000m 设计，对 R∈[1000,1500] 全程保证（任何实际半径都 ≤ 证书要求）；
- **边界情形**：圆缘朝外定向源（最坏检出条件）由外环 1900×12 点保证检出。

## 8　与其他问题的接口

- **问题 1**：MEC（最小覆盖圆）即其"定位区域最小包围圆"的判定工具，直接用于清除判据（MEC≤20m）；
- **问题 2**：单源示向度 + 第二测点交会，是 merged_walk 中"顺路补测"的理论基础（不同点示向度交会收缩候选域）；
- **问题 3**：全向源是问题 4 的特例（覆盖 360°），问题 3 的 7 点圆覆盖证书被 26 点环抱证书严格推广（环抱证书对全向源同样成立，且对定向源也成立）。

## 9　模型评价

**优点**：
1. **完整性可证明**：环抱证书是"判空 ⟺ maxgap≤180°"的**充要条件**，终止判定不依赖任何概率假设；
2. **统一性**：把全向源（360°）与定向源（闭 180° 半平面）的判空问题统一成同一个几何条件，理论优雅；
3. **信息复用**：清除源途中的测量点自动计入探针集合，判空与清除共享移动，无重复巡回；
4. **理论下界清晰**：26 点证书是穷尽验证的数学下界，600s 成绩有明确的可达性论证。

**局限**：
1. 证书巡回 3752s 是固定成本，源数少（10~11）时摊薄不足，T_avg 偏高；
2. 环抱证书按最坏接收半径 1000m 设计，若实际半径偏大则证书"偏保守"（但无法利用该信息，因半径未知）；
3. finalize 在 16/24 种子非零，仍有 ~460s 可优化空间（但已实验证明是接近极限）。
