## 1　问题重述

目标区域为半径 1800 m 的圆形区域（圆心为原点）。区域内有 **10–16 个全向干扰源**，个数、频道（1–20 互异）、位置、有效接收半径（1000–1500 m，逐源不同）均不可直接读取。机器狗从原点出发、初始频道 1，通过模拟器 HTTP 接口执行"移动+检测+清除"序列动作，要求：

1. **硬约束**：确保全部干扰源被清除（清除比例 = 100%）；
2. **目标**：平均定位清除时间 = 定位清除总时间 / 被清除个数，越小越好。总时间含移动、频道切换、检测、光学精确定位及清除，全部按虚拟时间计；
3. **时限**：`/enter` 后程序运行时间 ≤ 20 min（真实时间），25 min 测试窗口，虚拟时间上限 100 h（宽松）；
4. **交付**：充分演练后三次正式测试，按题面表 1 报告结果，导出日志文件。

关键物理规则（附录 1/2 与附件 2 提炼）：移动 5 m/s 直线；切换频道 1 s（**与频道间隔无关，只看是否不同于当前频道**）；单频道检测 5 s；检测须停止移动；**同一地点重复测量误差不变**；示向度误差有界 ±1°（非随机）；全向源在接收半径内**必**被检出（确定性检测）；距源 ≤ 20 m 可光学定位（3 s）+清除（2 s）；≤ 5 m 返回 `near` 可直接清除。

## 2　问题分析

### 2.1　任务分解与 MDP 形式化

```
① 发现（哪些频道有源、大致方向）→ 覆盖/搜索论 + 负信息
② 定位（每个源的位置保证区域）  → 交会定位 + 集员几何（问题 2 理论）
③ 接近与精定位（进入 20 m）     → 路径规划 + 长轴切割补测（问题 2 §5.8）
④ 清除（3 s + 2 s/源）          → 固定成本，5 s/源
⑤ 调度（先去哪、何时停）        → 在线路由 + 终止检验
```

**MDP 形式化**（论文问题分析章的规范语言）：

- **状态** $s=(p, c_{cur}, \{F_k\}, \{W_k\}, \{w_k\}, \mathcal{K}_{clr})$：当前位置、当前频道、各频道硬可行域、各源候选集、软后验、已清除集；
- **动作** $a \in \{(\text{measure}, p, ch), (\text{clear}, p, ch)\}$（移动隐含于 position）；
- **转移**：确定性物理规则 + 随机隐藏量（源位置、接收半径、示向度误差）；
- **代价**：$T(a)=\|p-p_{last}\|/5 + (5+1\!\cdot\![ch\neq c_{cur}])\ \text{或}\ (3\ \text{或}\ 5)$；
- **目标**：$\min \sum_a T(a)$，约束清除比例 = 1。

### 2.2　全局最优不可达，代之以三层目标

1. **精确求解不可行**：带隐藏状态的在线序贯决策（POMDP 族），最优策略是关于整个观测历史的函数；
2. **离线版本也 NP-hard**：即使源位已知，清除顺序是圆域 TSP（13 点 BHH 估算仅行驶 ~8000 m ≈ 1600 s），叠加测点选址优化；
3. **务实的三层目标**：

| 层 | 目标 | 手段 | 性质 |
|---|---|---|---|
| ① 完整性 | 清除比例 = 100% | 7 点覆盖证书 + 可行域排除（§5.6） | **可证明** |
| ② 决策局部最优 | 每步动作当前信息下最优 | 成本版自适应贪心 + 可选 rollout（§5.2/5.7） | 定理支撑 |
| ③ 平均近优 | 平均时间接近下界 | 离线"已知源位 TSP"benchmark 量化差距（§6.3） | 实证逼近 |

### 2.3　题目的五条结构红利

1. **频道即身份**：每频道最多一个源、频道互异 ⟹ 数据关联免费，"个数未知"退化为"20 个频道各自的存在性判定"，无需 RFS/粒子滤波重武器（提炼 05 §5）；
2. **负信息语义唯一**（问题 3 全向专属）：`no_signal` ⟺ 距离 > 接收半径 ⟹ 停点无信号 = "该源不在停点 1000 m 圆内"（最坏情形），多点累加收缩可行域；
3. **移动零实时代价**：移动只是 measure/clear 的 position 字段 ⟹ 20 min 真实时限对毫秒级在线优化极其宽松；
4. **检出即附送方位线**：一次检测同时给存在性 + ±1° 方向线 ⟹ 发现与定位可搭同一班车（免费交会）；
5. **同点重测无效**：信息只能靠换位置买（问题 2 秩 1 信息结构），否决一切"原地多测取平均"方案。

### 2.4　反轮询论证（信息驱动必要性的定理化）

20 频道暴力轮询 = m 射线星搜索：最优竞争比下加性项 $m\left((m/(m-1))^{m-1}-1\right)d$（Demaine et al. Thm 7，m=20 时 ≈ 33d ≈ 198 s），且选项数增大时代价按 $d^{3/2}$ 爆炸（Bansal et al. Cor 7，ℝ² 最优竞争比 9、随机化 4.591）。**结论：必须让每个示向度先验收缩后续搜索空间**——这是 §5.2 自适应贪心的动机段引理。

## 4　符号说明

| 符号 | 含义 |
|---|---|
| $F_k$ | 频道 k 的**硬可行域**（集员多边形）：k 源若存在则必在其中 |
| $W_k$ | 已检出频道 k 的候选集（方位带 ∩ 负信息，问题 2 语言） |
| $w_k(x)$ | 频道 k 的软后验（格点），Stone 式更新 |
| $p_d(x;S)$ | 停点 S 对格点 x 的检测力 $=P(R\ge\|x-S\|)$（1000 内 =1，1500 外 =0，环带内线性） |
| $S_{I,k}$ | 源 k 对测点集 I 的 bearing 散布矩阵 $\sum_i u_{ik}^\perp u_{ik}^{\perp\top}/d_{ik}^2$ |

| $\alpha$ | 探索倍增旋钮（权衡曲线 $cr=1+2\alpha^2/(\alpha-1)$） |
| $\Theta$ | SmartStart 阈值参数（开放情形 ≈2.05，竞争比 2.94） |
| $L$ | 当前可清除队列的 2-opt 收割巡回时长 |

| $\gamma_\psi$ | 自适应次模比（Fujii-Sakaue Def 3，兜底用） |
| $\eta$ | 可行域离散化格距（覆盖粒度，保证常数的参数） |
| $\mathcal{C}$ | 7 点覆盖证书构型（原点 + 1559 m 正六边形环） |
| $T_{avg}$ | 平均定位清除时间 = 总时间 / 清除个数（题目指标） |

**口径说明**：硬账用最坏情形（R=1000、±1° 全保留）保证正确性；软账用概率模型（R~U[1000,1500]）指导排序。二者永不混用判定（§5.1）。

## 5　模型建立（四模块 + 双账 + 主循环）

### 5.1　双账状态表示——硬集管保证、软后验管排序

每个频道同时维护两本账：

| | 硬账（集员） | 软账（贝叶斯） |
|---|---|---|
| 对象 | $F_k$ / $W_k$（凸多边形） | 格点后验 $w_k(x)$（格距 η=25–50 m） |
| `no_signal` 更新 | $F_k\leftarrow F_k\setminus B(S,1000)$ | Stone 式 (4.1)：$\tilde w=(1-p_d)w/\sum(1-p_d)w$ |
| `direction` 更新 | $W_k\leftarrow W_k\cap$ ±1° 带 ∩ $B(S,1500)$ | 按似然重权（带内保权、带外归零） |
| `near`/清除 | 直接清除，频道闭账 | 同左 |
| **权限** | **终止判定、清除可行性** | **仅优先级排序**（含 RPT* 收割排序） |

设计动机：题目要求"确保全部清除"是硬约束——**概率终止判据（后验低于阈值即停）在本题不可用**：后验 95% 停止意味着 5% 概率漏源，正式测试直接出局。而 1000–1500 m 环带内硬账只能保守全留、软账能分辨"这部分 60% 可能、那部分 20%"，排序确实更聪明——**两本账各取所长**。Stone 2014 [28] 的 AF447 搜救是该记账方式的实证（两年失败搜寻后按后验指导一周定位残骸）；$p_d$ 的位置依赖性（停点在候选域外 = 零证据）同时是扫描选点的过滤条件。

### 5.2　发现层：负信息贪心 = AdaptiveGreedy（升级 1）

**旧做法（v1）**：下一停点 = 覆盖残余可行域面积最大。无保证。

**定理化**（提炼 08 操作顺序）：

1. 各频道可行域离散化为格点假设集 $H_k$（version space）；目标 $f$ = 已排除格点质量；动作 = (停点, 频道) 对；
2. **三引理验证**（Javdani 模板 [6]）：
   - **L1 强自适应单调**：候选域运算只有 ∩（带/圆外/半平面），只缩不扩 → 有界误差语义下自动成立；
   - **L2 自适应次模**（G&K Def 3.3）：固定 (停点,频道) 在每个真实源位下剪除的格点集确定，且随历史增长只减不增 → 离散化后成立；R 区间不确定性按最坏情形（1000）处理；
   - **L3 self-certifying**（G&K Def 5.5 + Prop 5.6）：$f$ 只依赖已选动作的结果 → 自动成立；
3. 通过 ⟹ **面积贪心 = AdaptiveGreedy**：
   - 找齐式保证：$c_{avg}(\pi)\le\alpha\, c_{avg}(\pi^*)(\ln(Q/\eta)+1)$（G&K Thm 5.8；worst-case 版 Thm 5.9）；
   - **移动成本不均匀**（路费 ∝ 距离）→ 成本版规则 $\arg\max\ \Delta(e|\psi)/c(e)$，$c_\Sigma(\pi)\le 4\alpha c_\Sigma(\pi^*)$（Thm 5.10）；
   - **一停点连测多频道 = 批式**：批内各频道独立（H7）⟹ 对最优串行策略 (e/(e−1))² ln 因子（Chen-Krause Thm 1/2 [7]）；
4. **双叙事**：贝叶斯（均匀格点先验）走 G&K；**无先验对抗版**走 Yuan-Tang [8]（Def 1 + Thm 2：$c_{wc}\le(\ln(Q/\eta)+1)c^*$，纯集合语言，与题设"误差有界非随机"最贴）；
5. **失效兜底**：L2 验证失败（如负信息使可行域分裂非凸）→ 估计自适应次模比 $\gamma_\psi$，贪心仍有 $(1-\exp(-\gamma\ell/k))$ 型保证（Fujii-Sakaue Thm 1 [9]）。

**诚实边界**：离散化粒度 η 与保证常数耦合；论文须给"格距 25–50 m 时 L1–L3 仍成立"的验证说明。G&K Thm 12.1（不满足 Def 3.3 ⟹ 任意坏）是"验证不可省"的依据。

### 5.3　定位层：E/D 集员分数 + 问题 2 子程序（升级 2）

**精化评分**（替代 v1 的 $\sum w_k\sin\gamma_k$ 加权——Moreno 原文承认权值 "mission-dependent"，为文献公认空白）：

1. bearing 散布矩阵 $S_{I,k}=\sum_{i\in I}u_{ik}^{\perp}u_{ik}^{\perp\top}/d_{ik}^2$（视线法向外积 × 距离平方衰减；Sahu 式 26 [12]，与问题 2 FIM 结构同构）；
2. 候选停点 p 的精化分 $=\sum_k \mathrm{diam}(W_k)\cdot\Delta\log\det S_{I\cup\{p\},k}$（D 分数；Calafiore 实测 D 分数距 oracle 仅 4.1%、E 分数 6.2%、随机差 4.13 倍 [10]）；或最坏源优先用 E 分数 $\min_k\lambda_{\min}(S_{I,k})$；
3. **权值 = 候选域直径**（Calafiore Cor 1：$\mathrm{diam}\le\bar w\sqrt2/\sqrt{2\min S}$——域大者优先收缩，**权第一次可推导**）；
4. $1/d^2$ 距离修正内含（Sahu 式 26 与 Doğançay 式 7 ν≈0.2 互证 [12][32]）；
5. **2 源小引理**（Moreno 式 47 [13]）：某停点邻域恰有 2 个已检出源时，二阶矩平衡条件存在同时最优解（4 传感器 2 目标可同时达理论上限）——论文可写一条引理；
6. ≥3 源无同时最优（Moreno 已证）⟹ 加权和即 tradeoff 方案——**自建贡献①：多目标 bearing 一站的 E/D 分数**（检索确认的理论空白，见理论补强包 README §"已确认的理论空白"）。

**定位子程序**（问题 2 原样移植）：$W_k$ 配旋转卡壳直径、Welzl MEC、K-闭式；MEC > 20 m 时按长轴切割规则补测（$\rho=\max(50,0.5L)$，朝来路一侧，问题 2 数值验证一测把 164 m 区域压到 36 m）；`near` 直接清除。**免费交会**：探索停点携带的方位线直接计入 $S_{I,k}$——骨架点对（原点+环点、相邻环点）对相当比例源天然构成合格交会，预期 13 源中 8–10 个免专门定位（待演练校准）。

**事件触发测量**（Yousuf cep24 式 24 移植 [4]）：停点 p 对已检出频道 k 花那 6 s，当且仅当精化分 > 0（E/D 增益非零）且 $W_k$ 距 p ≤ 1500 且 MEC > 20 m。三重否决：共线零增益（秩 1 信息结构）、必无信号、已可清除。

### 5.4　停点内测量调度：约束结构定定理（升级 3）

```
预算怎么计?
├─ 按个数(停点内每项等长 6s) → uniform matroid
│    贪心 = 1-(1-1/k)^k   [Nemhauser; Liu Thm 3]
│    k=1 时贪心即最优; k=2: 0.75; k=3: 0.70   [Liu Remark 7]
└─ 按总秒数(含切换/移动摊销) → knapsack
     枚举≤3起始子集 + 效益/成本比贪心
     = (1-1/e)OPT - 2Lε/c_min, c_min=6s   [Sviridenko 2004 / KG2005, 经 krause2008 §4.3]
实现: CELF lazy greedy [21][33](Δ单调递减→优先队列惰性重估, 毫秒级)
仪表: Krause Prop 8 = 贪心解+top-k边际和 = OPT 上界 → 距最优还差多少的实时证书
```

次模性清单：频道检测收益**严格次模**（检出后归零，重复扫零增益——与"同点重测不变"题面规则天然一致）；精化收益走 §5.2 Javdani 框架。实际一停点测 3–8 个频道，k 小界远好于 1−1/e。

### 5.5　探索-收割切换：SmartStart + 单旋钮 α + 阶段式批量（升级 4）

**切换时机**（替代 v1 的 δ_detour 调参）：SmartStart 阈值 [14]

$$L(\text{收割巡回})\ \le\ (\Theta-1)\cdot t_{\text{已耗}}\ \Rightarrow\ \text{出发收割，否则继续探索}$$

开放情形（不需回原点）取 Θ≈2.05（竞争比 2.94；Θ=2 闭式情形精确为 2）。每完成一动作重估 L（可清除队列各 MEC 中心做 2-opt）。直觉读法："手头攒的活儿值不值得专门跑一趟"——早期 t 小 L 大自动不收割，后期源攒多自动触发，**自适应于任务成熟度**。

**单旋钮 α**（替代 w_e/w_c/λ 三个自由参数）：Angelopoulos Thm 2 [15] 证明不存在"探索快且最坏损失小"两头都占的策略，权衡曲线 $cr=1+2\alpha^2/(\alpha-1)$（α=2 即经典 9，最小值附近平坦）。操作化：未检出频道多（不确定性高）→ α 大激进探新；临近时限/已定位源密 → α≈2 最稳。**三个调参自由度坍缩成一个，取值有理论曲线指导**。

**收割批量结构**：SmartStart 触发后**阶段式批量**（圈定当前半径内全部可清除源 → 2-opt 排序 → 批量执行 → 回来继续探索 → 半径几何递增；Bienkowski 4-竞争 [17]），批内默认**环形序**（按极角排序不跳跃；Kamiński Thm 10：圆域最坏情形环形遍历最优、路径不自交 [16]）；探索期穿插访问按软账后验质量降序（RPT* 期望最优序 [20]）。

**诚实边界**：SmartStart/竞争比是**对抗性在线请求模型**（请求位置披露即确定），我们的"请求"由自身感知渐进产生（定位区域收缩中）、域为圆盘非线——**结构同构但非定理直接转移**；L 取"按当前候选域中心计的巡回长"并每测量后重估（SmartStart 本就逐时刻重估，结构兼容）。论文表述："策略结构采用……其竞争比保证作为设计依据，实际性能由模拟器演练统计验证"。

**收割子程序的路程保证**：沿示向度（±1°）直线逼近源 = 半平面射线搜索，竞争比 9.06–9.13 且区域限制只会帮忙（Langetepe [34]）——长轴切割/接近阶段的常数因子背书。

### 5.6　终止层：双层判据（硬证书 + 计数界）

**硬证书（完整性定理，论文可作命题）**：设停点集合含 7 点构型 $\mathcal{C}$（原点 + 半径 1559 m 正六边形顶点，覆盖半径 899.7 m < 1000 m，20 万采样点数值验证；6 点构型 1037.9 m 差 38 m 失败，与 Fejes Tóth 精确理论一致）。若频道 k 在全部 7 点均测且无信号，则 k 无源。

证明：圆域内任一点到 $\mathcal{C}$ 最近点 ≤ 899.7 m < 1000 m ≤ R_k；全向确定性检测（H3）⟹ 若 k 有源必在某骨架点被检出。∎

**Aldridge 计数界**（还要攒几次证据）[27]：确认频道 k 空的扫描次数下界 ≈ log₂(残余可行域可分辨单元数)（每测试 ≤ 1 bit）；可行域收缩后期很小 ⟹ 下界趋 0，不会无限攒证据。**Hwang 广义二分 remark**：最优测试位 = 覆盖残余域约一半处——当停点覆盖半径 1000 m、残余域 ~1500 m 尺度时，最大覆盖贪心与二分近似重合（§5.2 与本节在此会师，论文一句话 remark）。**自建贡献②**：位置依赖测试效力的群检测为检索确认的理论空白（Aldridge 计数界 + Stone 检测力模型组合自建）。

**终止条件**：全部 20 频道 ∈ {已清除} ∪ {$F_k=\varnothing$ 或覆盖证书生效}。软账**无否决权**（H9）。

### 5.7　决策深度：单步贪心 + 可选 1 步 rollout（升级 5）

- **理论**：以现有贪心为基策略 π，rollout 策略 $\tilde\pi$ 满足 $J_{k,\tilde\pi}(x_k)\le J_{k,\pi}(x_k)$ 对所有状态与时刻（Bertsekas Prop 2.1 [24]——**定理级不劣，非经验**）；
- **代价**：CMA-ES/MCTS ≈ 5–6 s/次 vs 浅层 rollout ~0.6 s/次（Rückin [26]）；我们单次停点检测本就 6 s 虚拟时间 + 真实时间宽松 ⟹ 付得起；
- **实现**：1 步 rollout——对 top-N 候选停点（**动作空间裁到 ~10²**，Rückin 在线可行性前提）各模拟一次后续贪心 + 终局代价估计；仿真模型用**确定性等价**（源 = 候选域中心，免先验建模负担）+ 截断视界（Bertsekas 官方省算力旋钮 [25]）；
- **决策**：选 rollout 不选 MCTS——MCTS 无对应不劣保证。增益由演练 A/B 定（§6.2）。

### 5.8　代价模型

$$T_{total}=\sum\frac{\|p_{a+1}-p_a\|}{5}+\sum_{\text{measure}}(5+\mathbb{1}[ch\neq c_{cur}])+\sum_{\text{clear}}(5)+3\cdot n_{fail}$$

（v1 对比项：切换与顺序无关（附件 2 §4.3），扫描顺序唯一收益是首测频道 = 当前频道省 1 s。）

### 5.9　主循环（v2 伪代码）

```
初始化: 硬账{F_k=圆域, W_k=∅}, 软账{w_k=均匀格点}, 已清除=∅
第一动作: 原点顺序扫 1..20 频道 (119 s = 19×1+20×5), 更新双账

while ∃频道 ∉ 已清除∪已排除:
    # 模式判定 (§5.5)
    L = 2-opt 收割巡回长(可清除队列各 MEC 中心)
    if L ≤ (Θ-1)·t_已耗:  模式 = 收割批次(环形序批量执行, 新源入下批)
    else:                模式 = 探索/精化

    # 候选动作生成 (动作空间 ≤ ~100)
    候选 = 未访问骨架点 ∪ 探索高分点(CELF 预筛)
         ∪ 各源 E/D 高分精化点 ∪ 软账集中频道的二分测试点

    # 评分 (§5.2 成本版贪心 + §5.3 E/D + α 旋钮)
    score(p) = α·Δ排除质量(p)/路费(p)              # 探索项
             + Σ_k diam(W_k)·Δlogdet S_{I∪p,k}      # 精化项
    (可选: top-5 候选做 1 步 rollout, 确定性等价)

    执行 argmax: 移动 → CELF 选频道组合逐个测 → 更新双账
    顺路规则: 途经点距某可清除源 MEC 中心 ≤ 20 m → 顺手 /clear

终止: 全部频道 ∈ 已清除 ∪ {F_k=∅ 或覆盖证书生效}   # 软账无否决权
/exit (真实时间看门狗: 预留 2 min 强制退出)
```

## 7　灵敏度与稳健性分析（论文该做的）

- **α/Θ 平台性**：预期权衡曲线在最小值附近平坦（Angelopoulos α=2 附近 cr 变化 <10%），演练给平台区间；
- **种子方差**：13 源随机布点的 $T_{avg}$ 分布（30 种子直方图），报均值±std 而非单例；
- **先验谱**：软账先验（面积均匀 vs 集中）对排序质量的影响——硬账保证不受影响（这是双账的卖点）；
- **最坏案例**：源全在 1500 m 外环带（原点零检出）——触发最坏发现成本，检验 7 点兜底；
- **边界情形**：源近圆缘（$D_{far}$ 掠射差异 ~100 m，问题 2 §7.3 已处理）、双源距离 < 150 m（交会互扰？——频道独立故无扰，但收割排序需合并）、`near` 源（直接清除路径）。

## 8　与其他问题的接口

- **问题 1**：$W_k$ 的多边形几何即其交付物（半平面求交 + 旋转卡壳 + Welzl）；
- **问题 2**：本模型定位层即其多源移植——赌注点、K-条件、长轴切割、κ 恒等式全部复用；问题 2 的"时间流派赌注 (500,250)"对应本问 SmartStart 早期（t 小）自动延迟收割的同一权衡；
- **问题 4**：仅 §5.1/§5.6 依赖全向假设——`no_signal` 语义改为"距离外 ∪ 覆盖角外"（并集语义，可行域收缩变慢），加一轮换构型重扫 + 朝向反演（Desrochers-Jaulin Minkowski 约束传播 [35]、Williams 主瓣边缘选点 [36]；**自建贡献③**：半平面带交集确定朝向的最少测点数，无现成闭式）。模块 2/3/主循环不动。

## 9　模型评价

**优点**：（i）完整性**可证明**（7 点覆盖命题）且终止不依赖概率假设；（ii）每个模块有定理：发现层 ln 型近似比（G&K/Javdani）、精化层近 oracle 评分（Calafiore 4.1%）、切换层竞争比结构（SmartStart/α 曲线）、调度层 1−1/e 族（Nemhauser/Sviridenko）、决策层不劣性（Bertsekas）——**七个"纯调参"缺口五个半被定理化**；（iii）双账设计化解"集员 vs 贝叶斯"之争：保证与效率各归其位；（iv）三个检索确认的理论空白可声明自建贡献（多目标 bearing E/D 分数、位置依赖效力群检测、朝向最少测点数）；（v）消融矩阵（§6.3）直接生成论文的敏感性分析章。

**局限**：（i）SmartStart/竞争比为结构类比而非定理转移（诚实声明 + 演练验证兜底）；（ii）L2 自适应次模性需离散化后逐条验证，η 与保证常数耦合；（iii）E/D 分数距 oracle 4.1% 是 range-only 场景的实测，bearing 版需自建推导（即自建贡献①，也是工作量）；（iv）时间预算数字（§6.1）全部待 mock 校准；（v）MDP 的状态空间含连续区域，rollout 的确定性等价在定位区域大时偏乐观，需 A/B 实证。
