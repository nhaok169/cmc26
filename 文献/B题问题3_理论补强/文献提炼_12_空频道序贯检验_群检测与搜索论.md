# 文献提炼 12：空频道的序贯存在性检验——群检测与搜索论（缺口 6）

> **用途**：为"对 4–6 个空频道攒不存在证据"的机制补理论：需要多少次扫描（计数界）、每次扫描如何记账与选位（负信息贝叶斯更新）、候选集带结构时界怎么变。
> **核心命题**：一次停点对某频道的 5 s 扫描 = 一次 0/1 存在性测试；确认"某频道空"所需扫描次数有信息论下界 ≈ log₂(候选假设数)；Hwang 广义二分法给出达到该界的自适应策略模板——**二分候选区域**；每次扫描的效果按检测力 p_d(x) 位置依赖地记账（Stone 式更新）。
> **诚实声明**：群检测文献中**不存在"测试效力依赖测试位置"的现成变体**（已系统检索，见 §5 覆盖报告）——该缺口需用 Aldridge 计数界 + Stone 检测力模型组合自建，论文可作为"最接近已知结果"引用并声明贡献。
> **可信度**：定理逐字提取自开放全文；Koopman 1957 与 Stone 1975 专著为付费墙（仅摘要），其可操作公式以 Stone 2014 开放文承担。

## 1. Aldridge, Johnson & Scarlett 2019/2026 —— 群检测的信息论视角（第二版）

**书目**：Matthew Aldridge, Oliver Johnson, Jonathan Scarlett. *Group Testing: An Information Theory Perspective*. Foundations and Trends in Comm. & Inf. Theory 16(3–4), 2019；**第二版 2026-05**，arXiv:1902.06002v4。全文：`fulltext/aldridge2019.txt`。

**核心定理（逐字）**：

> **Theorem 1.1 (Counting bound).** Any algorithm (adaptive or nonadaptive) for recovering the defective set with T tests has success probability satisfying **P(suc) ≤ 2^T / C(n,k)**. (1.7) …each test is a yes/no answer revealing at most 1 bit of information, we require at least log₂ C(n,k) tests.

> **Theorem 1.2 (binary splitting).** We can find all k defectives in a set of n items by repeated rounds of Algorithm 1.1, using a total of **k log₂ n + O(k) adaptive tests, even when k is unknown**.

> **Theorem 1.3 (Hwang 广义二分法的最优性).** Using Algorithm 1.2, we can find the defective set **with certainty using k log₂(n/k) + O(k) adaptive tests**. Thus, the capacity of adaptive group testing in the sparse regime is **C₀ = C = 1 for all α ∈ [0,1)**.（O(k) 项最好常数 0.255k，Allemann。）

> **Definition 5.2 (率).** rate := H(U)/T (5.19)…at least **H(U) tests** are required…

**算法（Algorithm 1.1，binary splitting，逐字）**：给定集合 A：(1) 测整池 A；负则停止；(2) A 单点则为缺陷；(3) 否则取半集 B 测试，正则 A:=B，负则 A:=A\B（**负测试仍保证 A\B 含缺陷**——负信息的 constructive 用法），回到 (2)。

**B 题映射**：
1. **要多少次**：确认"频道 c 空"的扫描次数下界 ≈ log₂(|该频道候选区域可分辨单元数|)（不是 1 次！——除非停点能一次覆盖整个候选区域且检测力为 1）；
2. **在哪测（策略模板）**：Hwang/binary splitting 翻译过来 = **对候选凸多边形反复对分，移动到能覆盖其中一半的位置测试**；负结果排除被覆盖的那一半（接收半径 ≥1000 m 保证单停点能覆盖相当大的半平面侧）；
3. **20 频道联合**：设已知 10–16 个源占去频道，空频道集合的假设数 ≈ C(20, k)，计数界给出整个"存在性+身份"任务的总测试下界语言。

## 2. Stone, Keller, Kratzke & Strumpfer 2014 —— 负信息的位置依赖记账（AF447 搜寻）

**书目**：Lawrence D. Stone, Colleen M. Keller, Thomas M. Kratzke, Johan P. Strumpfer. *Search for the Wreckage of Air France Flight AF 447*. Statistical Science 29(1) (2014) 69–80. DOI 10.1214/13-STS420. 开放版：`fulltext/stone2014.txt`。（Stone 即《Theory of Optimal Search》作者；Koopman 1957 与 Stone 1975 专著付费墙，仅摘要——引用原著须标二手。）

**核心公式（逐字）**：

> **式 (4.1)（未成功搜索的贝叶斯更新）**："If an unsuccessful search takes place, we compute the probability p_d(n) that the search would have detected the search object if it were located at x_n. The posterior probabilities:
> **w̃_n = (1 − p_d(n)) w_n / Σ_{n′}(1 − p_d(n′)) w_{n′}** (4.1)"

> **式 (4.2)（确定性检测律示例）**："1 − p_d(n) = { **0.1, if x_n is located in the search rectangle; 1, otherwise** }"

> 检测力位置依赖："…whether the path came within **1730 m lateral range** of the particle…"（距离外 p_d=0 → 更新因子 1 → **该停点对该粒子零证据**）；"we put a **maximum of 0.9** on estimates of sensor detection probabilities"。

**效果**：两年失败搜寻后，按该后验指导的 2011 年搜索**一周内定位残骸**（后验高处先搜——最优努力分配的离散实现）。

**B 题映射（与提炼 08 的自适应次模互补）**：这是"一次停点 = 一次有位置依赖检测力的存在性检验"的成熟外壳：
- 每个未检出频道维护粒子/格点候选集；停点扫描无信号后按 (4.1) 更新；
- 我们的 p_d(x) 由几何决定：停点对格点 x 的检测力 ≈ P(接收半径 ≥ ‖x−S‖)（R∈[1000,1500] 未知 → p_d 在 1000–1500 m 环带内从 ~1 平滑降到 0，恰好是文献"封顶 0.9"的位置对应物）；**停点在候选区域外 → p_d=0 → 零证据**——这正是"离候选区域远则无效"的定量表述，可直接用作扫描选点的过滤条件（不选 p_d≡0 的停点扫该频道）；
- Aldridge 管总数下界，(4.1) 管逐次记账与选位——两者组合即缺口的可用理论。

## 3. De Bonis 2023 —— 候选集带结构约束的群检测（最近邻结果）

**书目**：Annalisa De Bonis. *Group Testing in Arbitrary Hypergraphs and Related Combinatorial Structures*. arXiv:2307.09608v2 (2023). 全文：`fulltext/debonis2023.txt`。

**核心定理（逐字）**：

> **Theorem 2.** …For any positive integer p ≤ d−1, there exists a non-adaptive algorithm that allows to discard all but those hyperedges e such that |e \ e*| < p… and uses **t = O((d/p) log |E|)** tests.

> **Corollary 1.** …finds the defective hyperedge in E using at most t = O((d/p) log |E|) tests.
> **Corollary 2（两阶段）**：t = O(log |E|)；**Corollary 3（三阶段）**：t = O(√d log |E|)。

**B 题映射**：候选假设空间受限（哪些"频道-区域"组合可行，由已有负信息/圆域几何决定）时，测试次数从 O(log C(n,k)) 降到 **O(log|E|)|（|E|=可行假设数）**——为"负信息降低后续测试成本"给出定量语言。诚实结论：**无"测试效力位置依赖"变体**（见 §5），这是论文可声明的理论空白点。
