## 3. 提取的关键方法（原文公式）

### 3.1 FIM 基础链（原文 §3.1，与文献提炼01一致，互为印证）

CRLB：$\operatorname{cov}(\hat\theta) \succeq J^{-1}$；测向对目标位置的 FIM 贡献 = **沿垂直视线方向的投影矩阵**（信息只在垂直视线方向、随距离平方衰减）。

### 3.2 谱加权 FIM 目标（原文 §3.2 核心创新 1）

$$f_{\text{spec}}(u) = \sum_i \ln\lambda_i(J(u)) = \ln\det J(u)$$

- 与 D-最优 $\det J$ **同最优解**（对数单调变换不改变极值点）
- 但梯度行为不同：$\dfrac{\|\nabla f_{\text{spec}}\|}{\|\nabla f_{\text{dopt}}\|} = \dfrac{1}{\det J}$
- **退化几何附近**（视线共线，交会角 θ→0）：$\det J \sim C\theta^2$ → 谱加权梯度以 $1/\theta^2$ 发散，形成"排斥力"把规划器推离劣构型；而 D-最优梯度按 θ 线性趋零，优化器会**卡死**在共线附近
- 数值稳定：$\det J$ 跨 10 个数量级（10⁻⁶~10⁴），取对数后压缩到约 −14~+9，多目标函数加权不再被单项淹没

**B题用法**：机器狗在线选下一个检测点时，目标函数用 $\ln\det J$（或其负数做惩罚），天然回避"新点与已有示向线共线"的失败模式——这正是问题 2 中"避开第一示向线延长线附近"结论的**算法化实现**。

### 3.3 交会角正弦目标（原文 §3.3 核心创新 2，与 GDOP 三重等价）

双平台视线向量 $\mathbf{a}, \mathbf{b}$（目标指向平台），交会角 $\theta$：

$$f_{\sin} = \sin\theta = \frac{\|\mathbf{a}\times\mathbf{b}\|}{\|\mathbf{a}\|\cdot\|\mathbf{b}\|}$$

原文在等距对称假设下推导（式 15–21）：
- $\det(J_{\text{pos}}) = \dfrac{4\sin^2\theta}{\sigma^2 d^4}$ → θ=90° 时最大
- $\text{GDOP}^2 = \sigma^2\left(\dfrac{1}{2} + \dfrac{2}{\sin^2\theta}\right)$ → θ=90° 时最小
- **三重等价**：$\max\sin\theta \iff \max\det J \iff \min\text{GDOP}$

**B题用法**：选第二检测点时可直接用坐标无关的 $\sin\theta$ 作目标（计算量极小、无需算特征值），与文献提炼01（问题 2）的 90° 结论完全一致且给出等价性证明——论文里可将两者合并论证。

### 3.4 运动约束 PSO + 粒子归一化（原文 §3.4 核心创新 3）

- 优化变量是**航路点位置**（不是方向角——方向角作变量会生成不合理航路点）
- 运动学约束（最大速度/转弯率）嵌入粒子生成过程，保证轨迹物理可行
- 粒子多样性特征自动调整子目标权重（免手动调权）
- 适配 B题：粒子 = 候选检测点序列；约束 = 检测点须在未扫描区域/接收半径内、停点间隔可行驶

### 3.5 主动感知 / IPP 相关工作扫描（原文 §2，可作论文文献综述素材）

- 信息路径规划（IPP）比预定义覆盖模式显著更优：CMA-ES IPP 地图熵降 45%（Popović）；深度 RL IPP 比 CMA-ES 快 8-10×（Rückin）
- 绕目标**圆周运动**对静止目标可观测性最优（He et al.）；三维螺旋增强可观测性（Li et al.）
- 这些支撑问题 3 的核心论点：**自适应信息驱动选点 优于 固定覆盖模式**（但需与覆盖保证平衡，见文献提炼04）

## 4. 对问题 3 的直接启示

1. **在线选点算法骨架**：每步计算候选点的 $\ln\det J_{\text{累计}}$（含已测示向度的 FIM）+ 时间代价 → 择优；谱加权保证不陷入共线
2. **交会角正弦做轻量目标**：对单台机器狗的两停点交会，$\sin\theta$ 是零成本可计算的择点准则
3. **PSO 实现细节可复现**：粒子=航路点、约束嵌入、权重自适应（论文算法章可直接借鉴其流程图）
4. **99.21% 误差降幅**这一数字本身说明"几何优化"比"多测几次数"重要得多——机器狗应把时间花在"走到好位置"而不是"原地反复测"（且 B题同点重复测量误差不变，原地重测无意义！）
