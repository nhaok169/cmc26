## 2. 与 B题问题 3 的逐条对应（①②原文设定 vs 题目）

| 论文设定 | B题设定 |

## 3. 提取的关键方法（①图标 2022 全文）

### 3.1 估计层：RFS（随机有限集）+ SMC-PHD 粒子滤波

**核心思想**：用"强度函数" $D_k(x)$（粒子权重和表示）同时编码*目标个数期望*与*位置分布*——任意区域 $S$ 内粒子权重之和 = 该区域目标个数的期望：

$$\hat{N}_{k|k} = \sum_{j=1}^{L_k} \omega_k^{(j)} \quad\text{（目标总数期望 = 全部粒子权重和）}$$

- 预测：静态目标转移为 Dirac δ（目标不动），带存活概率 $p_s$；新生粒子从量测反演的 Gaussian 提议分布采样
- 更新：每收到量测集 $Z_k$，按检测概率 $\pi_d$ 与量测似然修正粒子权重
- **重采样**：粒子数自适应为 $L_k^+ = l\cdot\hat{N}_{k|k}$（每目标 $l$ 个粒子），消灭低权重复制高权重
- **B题映射**：粒子云 = "每个频道当前可信的源位置分布"；对 B题更简单——**每个频道独立一个单目标滤波器**（频道互不相同！），无需 RFS 的多目标关联复杂性，但"个数未知"问题转化为"哪些频道有源"的检测问题（见 §6 适配）

### 3.2 传感器模型（检测概率）

$$\pi_d(x, q) = G\,e^{-\|\zeta\|^2/2}, \qquad \zeta = \left(\tfrac{X_x - X_q}{F_X}, \tfrac{Y_x - Y_q}{F_Y}\right)$$

B题的对应物是**确定性检测律**（definite-range，Koopman）：$\pi_d = 1$ 当距离 ≤ 接收半径（1000–1500m），否则 0。论文的高斯软检测可平滑化处理"接收半径未知（1000–1500 区间）"的不确定性。

### 3.3 规划层：双目标贪心选点（论文核心创新）

$$q^*_{k+1} = \arg\max_{q_{k+1}\in Q_k}\Big\{\underbrace{I[x_{k+1}; \Lambda]}_{\text{目标精化（互信息）}} + \alpha\cdot\underbrace{\iota_k(x_{k+1})}_{\text{探索}}\Big\}$$

- **目标精化项** $I[x;\Lambda]$：下一位置与"是否收到空量测"二元事件的互信息（Dames & Kumar 2015 方法）——量化该位置对已见目标位置的改进价值
- **探索函数** $\iota$（**原创**）：网格初始化全 1，每步衰减
  $$\iota_k(x_{ij}) = \iota_{k-1}(x_{ij})\cdot(1 - \pi_d(x_{ij}, q_k))$$
  → 看得好的区域 $\iota\to 0$，没看过的区域 $\iota\approx 1$；当已见目标全部标记"找到"后，运动完全由探索项驱动，**自动退化为空间填充轨迹**
- **已找到目标的处理**：K-means 聚类粒子簇，簇宽度 $W_i \le T_W$ 且权重和 $\ge T_m$ → 判定"已找到"，存入 $\hat{X}$，并把来自该目标的量测从 $Z_k$ 中剔除 → **聚焦精化看得差的目标**（B题对应：已精确定位的源转入"前往清除"队列，不再占用检测资源）

### 3.4 仿真结论（①）

- 18 目标/3 簇 & 14 目标真实地形：**双目标法在"随时间发现目标数"曲线上全程优于 lawnmower（全覆盖扫描）和纯互信息法**
- 纯互信息法聚焦已见目标导致探索不足；lawnmower 均匀但盲目——**"信息驱动+探索兜底"的混合是本质优势**（与文献提炼04 的推荐架构互相印证）

## 4. 期刊完整版 ③（CEP 2024）的三项增量（对 B题更有用）

### 4.1 航路点与测量解耦（MPC 式框架）

选**远处航路点**（而非只选下一小步），沿途按周期 $\Delta$ 插入测量点；目标函数（原文式 17）：

$$w^* \in \arg\max_{w=1,\dots,W} \frac{-C(w) + \alpha\, T(w) + \beta\, E(w)}{K_d^w}$$

- $C(w)$：控制代价（输入平方和）→ **B题对应行驶时间**（5 m/s）
- $T(w) = \sum_{\tilde m}\sum_c \pi(\nu_c, q^w)$：沿预测轨迹所有测量点对已知目标簇中心的检测概率之和 → **目标精化价值**
- $E(w) = \sum_{\tilde m} \hat{e}(\tilde q)$：预测探索函数（同 §3.3 衰减律）之和 → **探索价值**
- 除以轨迹长度 $K_d^w$ 归一化，避免偏爱长轨迹
- **B题直接可用**：机器狗每次决策一个"下一停靠检测点"，沿途是否补测、测哪些频道全部可纳入此三目标结构

### 4.2 事件触发测量（原文式 24）——**B题最实用的一条**

测量（B题 = 停下 5s/频道 + 1s 切换）只在有价值时做：

$$\underbrace{\sum_{c=1}^{C_{k_m}} \pi(\nu_c^{k_m},\, q_{k_d,\tilde m})}_{\text{对已知目标的精化价值}} + \gamma\cdot \underbrace{e(\tilde q_{k_d,\tilde m})}_{\text{该处探索价值}} > \delta \;\Rightarrow\; \text{测量，否则跳过}$$

**B题映射**：在某位置是否停下扫某频道，当且仅当（a）该位置在该源定位区域附近（精化价值高）或（b）该区域从未被任何检测点覆盖过（探索价值高）。这正是把 119s 全扫成本从"每点必付"变为"按需付出"的判据，直接解决文献提炼04 §3.2 的"纯覆盖太贵"问题。

### 4.3 实机验证

Parrot Mammo 无人机 + TurtleBot3 地面机器人室内实验，优于 lawnmower、互信息法、主动搜索法与 2022 版方法——框架的工程可行性有实证。

## 5. 对 B题问题 3 的具体适配建议（本文档作者综合）

1. **逐频道独立滤波**：20 个频道各自维护"是否存在 + 位置粒子云/定位区域"。发现前是覆盖-探索问题；首次测得示向度后转入交会定位（问题 2 理论）；半径 <20m 或 5m 内直接清除
2. **个数未知的处理**：不必上完整 RFS——**频道独占**使"目标个数"= "有信号的频道数"，PHD 的作用退化为"每频道一个置信度/粒子云"，实现复杂度大降；终止判定 = 全部 20 频道满足"已清除 或 被负信息排除"（未检出 + 该源可能区域被 7 点覆盖表完全覆盖 ⇒ 不存在）
3. **探索函数直接落地**：$\iota$ 网格初始化 1，检测点覆盖处以 $(1-\pi_d)$ 衰减（B题可取阶跃式：覆盖过→0，未覆盖→1）；配合 7 点覆盖表即得"自适应选点 + 兜底"的完整算法
4. **三目标选点函数**（融合 4.1 与 B题时间结构）：
   $$\text{score}(w) = \frac{-\frac{\text{行驶时间}}{5} - 5\cdot|\text{待扫频道}| - \text{切换}}{K} + \alpha\, T(w) + \beta\, E(w)$$
   供建模会话在模拟器上调参验证

## 6. 与 B题的差异警示

| 论文 | B题 | 适配 |
|---|---|---|
| 量测含**距离+方位** | 只有**方位**（示向度） | 单点不可定距 → 必须两点交会（问题 2 理论）；粒子更新退化为"沿方位线的带状权重" |
| 检测软概率（高斯 FOV） | 确定性检测（半径内必测到）+ 半径本身未知（1000–1500） | 用保守 1000m 做覆盖保证；负信息推理时用区间 |
| 无人机连续飞行测量 | 必须**停下**且逐频道 5s | 测量是重成本 → 事件触发判据（4.2）价值放大 |
| 目标静止、找位置即结束 | 找到后还要接近 ≤20m 光学定位+清除 | 增加 Phase C/D（文献提炼04 §4） |
