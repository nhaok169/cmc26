## 核心结论速览（详见文献提炼04/05）

- **覆盖保证**：最坏接收半径 1000m 下，7 个检测点（中心+1559m 正六边形环）才能保证 1800m 圆盘全覆盖；6 点差 38m 失败（与 Fejes Tóth 理论一致）
- **纯覆盖扫描不划算**：7 点全扫 20 频道共 ≈45 min 虚拟时间 → 走"自适应信息驱动 + 覆盖兜底"混合策略
- **定位链**：两点交会（90°、靠近）定位区域外接圆半径 28.5m > 20m 光学半径 → **需 ~400m 处补第三测**（区域缩至半径 <12m）
- **单源流水线理想成本 ≈ 386s**；未检出是负信息，可收缩剩余源区域并作终止判定
- **在线选点**：目标函数用 $\ln\det J$（谱加权）或 $\sin\theta$（交会角正弦），与问题 2 的 90° 结论三重等价
- **事件触发测量**（Yousuf 系列 cep24 式24）：只在"对已知源有精化价值 或 该区域未探索过"时才停下扫描——把 119s/点的全扫成本变为按需付出，直接解决纯覆盖太贵的问题
- **未知个数处理**：B题频道独占 ⇒ 每频道独立"存在性+位置"滤波，RFS 复杂性大降；终止判定 = 全部 20 频道"已清除 或 被负信息+覆盖表排除"
