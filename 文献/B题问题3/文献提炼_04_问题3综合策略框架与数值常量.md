## 1. 问题 3 的任务结构分解

```
任务：清除全部 10-16 个未知位置的全向干扰源，最小化 平均定位清除时间 = 定位清除总时间 / 清除个数
     （总时间 = 移动 + 频道切换 + 检测 + 光学定位 + 清除）
     约束：程序运行时间 ≤ 20min（真实时间）；虚拟时间上限 100h（宽松）；25min 测试窗口

子问题分解：
① 发现（哪些频道有源、大致方向）→ 覆盖/搜索论
② 定位（每个源的位置估计）      → 交会定位 + FIM 几何（问题 2 理论）
③ 接近与精定位（进入 20m）      → 路径规划 + 近距离补测
④ 清除（3s 光学 + 2s 激光）     → 固定成本 5s/源
⑤ 全局调度（先去哪后去哪、何时停止搜索）→ TSP/在线决策 + 未知目标数处理
```

|---|---|

| 光学精确定位 | 3 s（须距源 ≤20m） |

## 3. 数值验证常量（本会话独立计算，论文可直接引用）

### 3.1 检测点覆盖布置（圆覆盖数值实验，采样 20 万点+边缘加密）

目标：半径 1800m 圆盘内任一位置都落在某检测点 1000m（最坏接收半径）内。

| 检测点数 n | 最优构型的覆盖半径 (m) | r=1000 保证覆盖？ |
|---|---|---|
| 4 | 1271.6 | ✗ |
| 5 | 1110.6 | ✗ |
| 6 | 1037.9 | ✗（差 38m，与 Fejes Tóth 小 n 精确覆盖理论一致：6 圆覆盖单位圆最优比 ≈0.556） |
| **7** | **899.7** | **✓（中心 + 1559m 环上正六边形）** |

- Kershner 下界：N ≥ 1.209·(1800/1000)² = 3.92 → N≥4（大区域渐近，小 n 偏松）
- **保证性覆盖需 7 个检测点**（构型：原点 + 环半径 1559m 的正六边形顶点）
- 若接收半径均为 1500m（乐观），4 点即可；**7 点方案对任意接收半径组合都成立**

### 3.2 扫描时间成本

| 项 | 数值 |
|---|---|
| 单点全扫 20 频道 | 19×1s + 20×5s = **119s** |
| 7 点全扫（不含移动） | 833s ≈ 13.9 min |
| 7 点巡回行驶（最近邻，不返程） | 9352m → 1870s ≈ 31.2 min |
| **全覆盖扫描方案总时间** | **≈ 2703s ≈ 45 min（虚拟）** |
| 原点单点检测的面积覆盖比 | 31%（r=1000）~ 69%（r=1500） |

**推论**：穷举式全覆盖扫描虽"保证"，但平均每源成本 ~200s+，且未含定位清除——**纯覆盖策略不是好策略**；应利用每次检测的示向度信息（一次检测同时给出"存在性+方向线"）走自适应路线。反之，**覆盖保证可作为兜底逻辑**：当自适应流程结束时，用 7 点覆盖检查表核对未检出频道，避免漏清。

### 3.3 定位→接近→清除的量化链（衔接问题 2 结论）

| 量 | 数值 | 推论 |
|---|---|---|
| 两点交会（r₁=r₂=1000m, 90°）定位区域直径 | 49.4m（=2tan1°·√(r₁²+r₂²)，文献提炼01公式） | — |
| 该区域外接圆半径上界（Jung 定理 ≤ D/√3） | 28.5m **> 20m 光学半径** | 两点交会**不足以**保证直接光学锁定 |
| 近距离第三示向度（r≈400m 处再测一次） | 区域直径缩至 ~20m，外接圆半径 ≤11.4m < 20m | **推荐：接近后补第三测**，然后区域中心即光学可达 |
| 单源典型流水线（首测 5s + 移 700m/5m/s=140s + 复测 6s + 接近 1000m=200s + 近距补测 ~30s + 光学 3s + 清除 2s） | **≈ 386s/源** | 16 源全流程理想下限 ~1.7h（虚拟），远优于全覆盖方案的分摊 |

### 3.4 关键机理提醒（题目特有）

1. **同点重复测量无效**：同一地点电磁环境误差固定，重测同一频道不改变示向度——FIM 中同点多次测量不新增信息（与文献高斯独立噪声假设的差异，文献提炼01 §4.2 已述）
2. **未检出是信息**：在某点扫频道 c 无信号 ⇒ 频道 c 的源距该点 > 其接收半径。多点累积可**收缩剩余源的可能区域**（搜索论负信息/Bayesian 更新），这是"何时停止搜索"的判定基础
3. **频道切换开销与顺序**：从频道 a 到 b 恒 1s（与间隔无关）→ 扫描顺序不影响切换成本（n 个频道 n−1 次切换），但**初始频道 1 出发**意味着首次全扫从 1 开始顺序扫即可
4. 20 频道 vs 10–16 源：**至少 4 个频道空置**；全扫一点 119s 中约 20–50s 花在空频道上——第二点起只扫"已发现且未清除"的频道可大幅省时

## 4. 推荐策略架构（分阶段 + 分层，供建模会话组装）

```
Phase A 全局发现（粗扫）
  - 在少量关键点全频道扫描（首点=原点，覆盖 31-69% 面积）
  - 后续粗扫点按"覆盖补盲 + 负信息收缩"选取（可预置 7 点覆盖表作为骨架）
  - 每次检出频道 → 记录 (检测点, 示向度) 进入定位队列

Phase B 逐源定位（复用问题 2 理论）
  - 对每个已发现源：按交会角≈90° + 尽量靠近源 选第二检测点（sinθ 目标，文献提炼03）
  - 源位置未知 → 对第一示向线上的先验段做最坏情形/加权最优（文献提炼01 §4.4）
  - 可与 Phase A 协同：粗扫点的选择同时为已发现源提供交会（一石二鸟）

Phase C 接近与精定位
  - 移动至定位区域中心（若两测不够近，途中 ~400m 处补第三测，区域缩至 <20m 半径）
  - 距源 ≤20m：光学定位 3s；（若 ≤5m 直接光学+清除，跳过测向）

Phase D 清除
  - 激光 2s；从待扫频道表中删除该频道

Phase E 调度与终止判定
  - 已定位源间的访问顺序：TSP/最近邻/贪心（按 平均定位清除时间 目标，等效最小化总时间）
  - 终止：全部 20 频道要么已清除要么被负信息排除（结合 7 点覆盖核对表兜底）
```

**在线 vs 离线的混合**：预计算 7 点覆盖表 + 在线信息驱动选点（Xiao 2026 的谱加权 FIM/PSO 机制）——覆盖保证做安全网，信息驱动做加速器。论文可做成两方案对比（全覆盖基线 vs 自适应策略），用模拟器演练统计量（清除比例、平均时间）呈现改进幅度。

**多目标权衡的目标函数建议**（供优化模型使用）：
$$\min \; T_{\text{总}} = \sum \text{移动} + \sum \text{扫描} + \sum \text{定位补测} + 5\text{s}\times\text{清除数}$$
约束：每源至少 2-3 次不同检测点测量、交会角 ∈[60°,120°]、末次测量距离 ≤ ~400m、全频道覆盖保证。
